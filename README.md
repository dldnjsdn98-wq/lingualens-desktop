# LinguaLens for Windows

게임 스크린샷의 문구를 검증하는 Windows 앱입니다. 본인 계정으로 로그인한 Codex CLI 또는 Gemini CLI로 이미지의 글자를 추출하고, 앱이 문구의 대소문자·공백·기호·지정 영역을 비교합니다.

## 설치

[최신 릴리스](https://github.com/dldnjsdn98-wq/lingualens-desktop/releases/latest)에서 `LinguaLens-Setup-<버전>.zip`을 내려받아 압축을 풀고 `Install.cmd`를 실행하세요. 설치 없이 사용하려면 `LinguaLens-Windows.zip`을 풀어 `LinguaLens.exe`를 실행할 수 있습니다. Microsoft Edge가 필요합니다.

앱 안에서 사용할 CLI를 선택하고 로그인 창을 열어 각 서비스 계정으로 로그인하세요. 계정 비밀번호와 토큰은 이 앱에 입력하지 않습니다.

0.2.0부터 앱 실행 시 새 정식 릴리스를 확인해 자동으로 내려받아 설치합니다. GitHub 릴리스의 SHA-256 해시와 ZIP 파일 구성을 검사합니다. 기존 0.1.1 사용자는 0.2.0을 한 번 수동 설치해야 합니다.
