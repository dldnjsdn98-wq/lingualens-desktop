# Language Test

스크린샷의 글자를 로컬 OCR 또는 개인 계정으로 로그인한 공식 CLI가 추출하고, 기존 비교 로직이 문구별 일치 여부를 판정하는 Windows 앱입니다.

**0.4.3:** 검수 검색·필터·단축키, 메모 자동 저장, 영역 잠금·다중 편집, 미니맵·화면 설정 저장, 작업 프로필, OCR 읽기 순서, 취소 가능한 비교·슬라이더·기준 이력을 포함합니다. [전체 변경 사항](CHANGES-0.4.3.md), [검증 결과](VALIDATION-0.4.3.md)를 확인하세요. Debian 13 x64 소스·모델·테스트 배포는 [Linux 실행 안내](LINUX.md)를 따르세요.

## 실행

Windows 첫 설치는 [최신 릴리스](https://github.com/dldnjsdn98-wq/lingualens-desktop/releases/latest)의 `Language-Test-Setup-0.4.3.zip`을 받아 압축을 풀고 `Install.cmd`를 실행하세요. Linux는 `Language-Test-Linux-x64-0.4.3-preview.tar.gz`를 사용합니다.

1. 배포 ZIP을 풀고 `LinguaLens.exe`를 실행합니다. Microsoft Edge가 필요합니다.
2. 기본 `빠른 로컬 OCR`은 실행 환경과 모델이 포함되어 있으며 설치·로그인·API 키 없이 사용할 수 있습니다. AI로 분석하려면 Codex 또는 Gemini를 선택합니다. 앱은 Codex 데스크톱 앱에 포함된 CLI와 공식 Antigravity CLI의 일반 설치 경로를 확인합니다. 도구가 없다면 앱의 `설치 방법 보기`에서 공식 안내를 열 수 있습니다.
3. 로그인이 필요하면 `웹페이지에서 로그인`을 누릅니다. Google은 열린 Antigravity 창에서 Google OAuth를 선택합니다. 브라우저에서 받은 인증 코드는 해당 Antigravity 창에 붙여넣습니다. 로그인 확인 후 앱에 `로그인됨`으로 표시됩니다. 별도 API 키는 필요하지 않습니다.
4. 이미지를 선택하고 오른쪽에 검증 문구를 입력한 뒤 `현재 이미지 검증`을 누릅니다. 여러 장을 선택하면 `선택한 N장 검증`으로 바뀝니다. Excel의 시트·범위·열 가져오기와 영역 지정도 사용할 수 있습니다.

CLI를 별도로 설치한 뒤에는 앱에서 `로그인 상태 다시 확인`을 누르세요. 앱은 비밀번호나 토큰을 요구하지 않습니다. 로그인 권한과 사용량은 해당 계정 및 CLI 정책에 따릅니다. Google Cloud 프로젝트 OAuth Client ID/Secret은 데스크톱 앱에 필요하지 않습니다.

`Install.cmd`를 실행하면 현재 사용자에게 설치하고 바탕 화면 및 시작 메뉴에 바로 가기를 만듭니다. 설치 없이 배포 폴더의 `LinguaLens.exe`를 실행해도 됩니다. 최근 10건 기록은 Edge 앱 프로필의 로컬 저장소에 보관됩니다.

앱 창이 열려 있는 동안 로컬 서버가 실행됩니다. 앱을 닫으면 약 2분 뒤 서버가 종료됩니다. 같은 PC에서 앱을 다시 열면 실행 중인 서버를 재사용합니다.

## 자동 업데이트

0.2.0부터 앱은 실행할 때 [공개 GitHub 릴리스](https://github.com/dldnjsdn98-wq/lingualens-desktop/releases/latest)를 확인합니다. 새 정식 버전이 있으면 `LinguaLens-Windows.zip`을 내려받고, GitHub가 제공하는 SHA-256 해시와 ZIP 구성 및 버전을 확인한 뒤 앱 파일을 교체해 다시 엽니다. 다운로드에 실패하면 현재 버전으로 실행합니다. 사용자 기록은 별도 Edge 앱 프로필에 보관됩니다.

0.1.1 이하 버전에는 업데이트 기능이 없으므로 0.2.0을 한 번 설치하거나 압축을 풀어 실행해야 합니다. 이후에는 새 릴리스가 게시되면 다음 실행 때 자동으로 갱신됩니다.

화면 상단의 `v버전 · 최신 확인`을 누르면 현재 설치 버전과 GitHub의 최신 버전을 바로 비교할 수 있습니다. 0.2.1부터 앱마다 별도 로컬 서버를 열어 이전 버전의 서버 화면이 재사용되지 않습니다.

0.2.2부터 로그인 버튼은 PowerShell 도우미 없이 공식 CLI의 브라우저 로그인 흐름을 시작합니다. 로그인 결과를 앱 화면에서 확인할 수 있습니다.

0.2.3은 Codex가 표준 입력 종료를 기다리며 멈추던 문제를 수정합니다. 분석 경과 시간을 표시하고, 응답 제한 및 취소를 실제 실행에 전달합니다. Gemini는 로그인 정보 파일뿐 아니라 인증 방식 설정도 확인합니다. Google 서버가 계정의 Gemini CLI 사용을 거절하면 해당 원인을 표시합니다.

새 버전을 배포할 때는 `version.txt`를 올리고 `Build-Release.ps1`을 실행한 뒤, 출력된 `LinguaLens-Windows.zip`을 같은 이름으로 새 정식 GitHub Release에 첨부합니다. 첫 설치용 파일 이름은 `Language-Test-Setup-<버전>.zip`입니다. 자동 업데이트 ZIP 이름과 내부 실행기·설치 경로는 기존 사용자와의 호환성을 위해 유지합니다. 릴리스 태그는 `v<version.txt>`와 일치해야 합니다. 드래프트나 사전 공개 릴리스는 업데이트 대상이 아닙니다.

## 개발

이 저장소의 기본 브랜치에는 앱 소스·테스트·Windows 빌드 스크립트·Linux 실행 스크립트가 있습니다. Node.js 20 이상에서 아래 명령으로 공통 로직을 검사할 수 있습니다.

```sh
git clone https://github.com/dldnjsdn98-wq/lingualens-desktop.git
cd lingualens-desktop
node --test tests/*.test.mjs
node src/server.js
```

브라우저 라이브러리는 `vendor/`에 포함하므로 공통 테스트에 별도 npm 설치는 필요하지 않습니다. OCR 런타임·대용량 모델·설치 파일은 Git에 넣지 않습니다. Windows OCR 번들은 Python 3.12에서 `python Prepare-OCR.py`로 준비한 뒤 `Build-Release.ps1 -NodePath <node.exe 경로>`로 빌드합니다. Linux에서 실제 OCR도 실행하려면 최신 Linux 패키지의 `vendor/ocr/`를 같은 경로에 복사하고 [Linux 실행 안내](LINUX.md)를 따르세요. CLI 실계정 로그인과 실제 OCR은 공통 자동 테스트와 별도로 확인합니다.

Node.js 20 이상에서 `node src/server.js`를 실행하면 로컬 URL이 표시됩니다. `node --test tests/*.test.mjs`로 모의 CLI 응답의 문구 판정을 확인합니다. 런처와 업데이터는 Windows .NET Framework C# 컴파일러로 빌드합니다. `node.exe`, `src`, `vendor`, 두 실행 파일, `version.txt`, `release-channel.json`을 배포 폴더에 포함해야 합니다.

Codex는 공식 `codex exec`의 이미지 및 출력 스키마 옵션을 사용합니다. Google은 Antigravity의 `-p`, `@image`, `--json-schema`, `--mode plan`, `--sandbox`를 사용합니다. CLI가 읽어야 하는 이미지 사본은 작업별 임시 폴더에 만들고 종료 후 삭제합니다. 최종 판정은 `src/matcher.js`에서 수행합니다.

0.2.4부터 동일 이미지의 OCR 결과를 프로세스 메모리에 최대 12건, 5분 보관합니다. 문구가 바뀌면 저장된 글자로 새로 비교합니다. `이미지 새로 읽기`는 캐시를 무시합니다. 도구와 설정 파일 변경도 구분합니다. 모델은 각 줄을 한 번만 출력하고 전체 텍스트는 앱에서 조합합니다.

0.2.5는 드래그 중 자동 스크롤로 좌표가 어긋나는 문제와 재시도 후에도 남던 영역 크기 경고를 수정합니다. 기본 `빠르게 읽기`는 낮은 추론 수준으로 전체 글자만 추출합니다. `좌표까지 자세히 읽기`는 기존 설정과 글자별 좌표를 사용합니다. 서로 다른 영역이 섞인 검증은 빠른 모드에서도 좌표를 포함합니다. 모든 항목이 같은 영역이면 해당 부분만 원본 크기로 잘라 분석하고, 결과 좌표를 원본 화면에 다시 대응시킵니다. 첫 결과를 즉시 표시하고 확대 재인식은 결과 화면에서 선택하여 실행합니다. 모드와 좌표 필요 여부가 바뀌면 OCR 캐시를 구분합니다.

현재 자동 테스트는 모의 OCR로 HTTP 업로드·영역·문구 비교를 확인합니다. 실제 Google/ChatGPT 로그인과 실계정 OCR은 각 사용자 로그인 후 확인해야 합니다.

## 작업 이미지 폴더 (0.2.6)
- 여러 이미지(최대 20장, 합계 80MB)를 추가하고 각 이미지에 문구와 영역을 따로 설정합니다.
- 모든 이미지 검증으로 순서대로 실행하고 이미지 버튼에서 각 결과를 확인합니다.
- 폴더와 작업 이름을 입력한 뒤 앱에 저장을 누르면 원본·설정·결과가 이 PC에 저장됩니다.
- 저장한 작업 폴더 열기에서 폴더를 골라 다시 엽니다. 폴더명을 변경해 저장하면 이동합니다.
- 저장 위치: %LOCALAPPDATA%\LinguaLens\projects. 앱 업데이트와 별도로 유지됩니다.
- 작업 파일 내보내기/가져오기로 백업할 수 있습니다. 파일에는 원본 이미지가 포함됩니다.
- 변경 사항은 앱에 저장 버튼으로 저장합니다. 저장 전 종료하면 확인 창이 표시됩니다.
## 안정성 개선 (0.2.7)
- 문구·언어·좌표·항목을 변경하면 이전 결과를 지우고 재검증 필요 상태로 표시합니다.
- 저장·불러오기·이미지 준비·분석 중에는 해당 작업의 설정과 이미지 전환을 잠시 잠급니다.
- 전체 검증 후 버튼의 이전 활성화 상태를 복원합니다. 오류가 있으면 완료 메시지에 건수를 표시합니다.
- 백업 파일 내보내기는 앱에 저장 상태와 별도로 관리합니다.
- 작업 파일의 문구·좌표·결과 형식을 저장과 복원 시 함께 검사합니다.
- 저장 목록은 파일 변경 여부를 확인해 요약 정보를 재사용하고, 손상된 파일은 다른 작업 목록을 막지 않습니다.

## 빠른 OCR과 작업 정리 (0.3.0)

- RapidOCR는 이 PC에서 원본 이미지의 글자·좌표를 읽습니다. 한국어는 PP-OCRv5 한국어 모델을, 중국어 간체·번체·일본어·영문 및 유럽 언어는 PP-OCRv6 small 모델을 사용합니다. 한국어와 중국어·일본어가 함께 지정된 작업은 두 모델을 실행합니다. 문구 언어를 화면에 맞게 선택하세요.
- 선택한 결과의 영역을 로컬 OCR·Codex·Gemini 중 하나로 다시 확인할 수 있습니다. 영역이 없고 가까운 인식 위치도 없으면 검증 영역을 먼저 지정하세요.
- 이미지 목록에서 손잡이 드래그 또는 ↑↓ 버튼으로 순서를 바꿉니다. 체크한 이미지에 현재 문구·언어·영역을 복사하거나 선택한 이미지만 검증할 수 있습니다. 미통과·미검증 다시 확인은 이미 통과한 이미지를 제외합니다.
- 저장 목록에서 폴더 이동을 하면 원본 이미지를 다시 저장하지 않고 폴더 정보를 바꿉니다.
- 저장한 원본 이미지는 별도 파일로 보관하며 같은 이미지는 공유합니다. 기존 작업과 JSON 백업을 계속 읽을 수 있습니다. 기존 저장 파일을 새 방식으로 저장하면 `.legacy-backup` 사본을 남깁니다. JSON 백업 내보내기에는 계속 원본이 포함됩니다.
- OCR 글자·좌표는 `%LOCALAPPDATA%\LinguaLens\ocr-cache`에 최대 128건·7일 보관해 앱 재실행 후에도 재사용합니다. 원본 이미지·기대 문구·계정 토큰은 OCR 캐시에 포함하지 않습니다. 이미지 새로 읽기는 캐시를 무시하고 OCR 캐시 비우기로 저장 캐시를 지울 수 있습니다.
- 제공된 게임 화면 시험에서 번들 OCR의 첫 전체 분석은 약 3.5초, 준비된 엔진의 말풍선 분석은 약 0.6초였습니다. 전체 정확도나 모든 PC에서의 처리 시간을 보장하는 값은 아닙니다. 작은 글자·어두운 배경·장식 폰트에는 오인식이 있어 선택 영역 재확인을 활용하세요.

로컬 OCR 모델의 버전·출처·SHA-256은 `vendor/ocr/manifest.json`에 포함됩니다. 배포 빌드에는 준비된 OCR 번들을 함께 넣습니다.

## 인식 재확인과 자동 복구 (0.3.1)

- 일치하는 글자의 인식 점수가 0.8 미만이거나 같은 위치에 서로 다른 높은 점수의 인식 결과가 있으면 `확인 필요`로 표시합니다. 인식 점수는 정확도를 보장하는 확률이 아닙니다. 기존 저장 결과도 열 때 이 기준으로 다시 확인합니다.
- 기본 자동 재확인은 불확실한 작은 영역 최대 3곳을 원본에서 잘라 확대해 로컬 OCR로 확인합니다. 도구 선택에서 로컬 후 Codex/Gemini를 고르면 로그인한 경우 남은 영역 최대 2곳을 해당 AI로 이어서 읽습니다. 영역을 찾을 수 없거나 화면의 40%보다 큰 영역은 자동 재확인을 생략하므로 직접 영역을 지정하세요.
- 미통과·미검증 다시 확인은 이전 결과가 있으면 실패한 영역을 읽고 완료 결과를 유지합니다. 위치가 없는 경우 전체 OCR 결과를 재사용하거나 다시 읽습니다.
- 휴대폰 JPEG의 EXIF 회전 정보를 적용해 미리보기와 로컬 OCR의 방향·좌표를 맞춥니다. 한국어와 중국어/일본어가 함께 있는 작업은 위치·방향 탐지를 공유합니다.
- 변경 사항은 약 2.5초 뒤 PC의 `projects/drafts`에 자동 임시 저장합니다. 분석·불러오기가 끝난 뒤 저장하며, 다음 실행의 `임시 작업 복구`에서 다시 열 수 있습니다. 정식 작업 저장과 구분되며 `앱에 저장`하면 임시 사본을 지웁니다. 저장 전 순간적인 종료나 저장 실패 때는 마지막 변경이 남지 않을 수 있습니다.
- 이미지 삭제 취소는 현재 작업에서 최근 10개까지 지원합니다. 저장 작업 삭제는 휴지통으로 이동하며 `휴지통에서 복원`으로 원본·결과를 복원합니다.
- 저장 목록을 작업/폴더 이름과 통과 상태로 찾습니다. 자주 쓰는 문구·언어·영역 설정을 저장하고 다른 이미지에 적용합니다. 화면 비율이 다르면 문구만 복사가 기본이며 복사 미리보기에서 영역 포함 여부를 선택합니다.
- 폴더 선택과 FilePond의 폴더/파일 드롭·붙여넣기로 이미지를 가져올 수 있습니다. 폴더 선택은 하위 경로를 이미지 이름에 보존합니다. 20장·80MB 제한은 계속 적용됩니다.
- Codex는 공식 App Server의 상주 연결과 별도의 임시 대화를 사용합니다. 진행 상태를 표시하고 취소·시간 제한 때 앱이 시작한 프로세스를 종료합니다. 서버 연결을 지원하지 않는 CLI는 분석 전 기존 실행 방식으로 돌아갑니다. 이미 시작한 AI 분석은 자동으로 중복 실행하지 않습니다. 모델 응답 속도는 계정·모델·이미지에 따라 다릅니다.
- SheetJS CE를 공식 0.20.3 배포본으로 갱신했습니다. FilePond 4.32.12와 라이선스를 포함합니다. 복구 데이터는 포트가 바뀌어도 유지되도록 브라우저 저장소 대신 PC의 작업 저장소에 보관합니다.

## 작업 화면 (0.3.2)

- 왼쪽 이미지 목록, 가운데 원본 이미지, 오른쪽 문구 설정·검증 결과를 함께 표시합니다. 이미지를 추가한 뒤에는 큰 업로드 안내를 접고 `이미지 추가`·`폴더 추가`를 사용합니다.
- 결과 항목을 누르면 가운데 이미지에서 해당 인식 영역을 확대합니다. `화면 맞춤` 또는 이미지 두 번 클릭으로 전체 화면을 보고, `이동` 도구로 확대된 이미지를 드래그할 수 있습니다. Ctrl+휠로 확대·축소합니다.
- `선택` 도구에서 영역 박스를 끌어 이동하거나 모서리·변의 손잡이로 크기를 바꿉니다. `영역 그리기`는 현재 문구에 새 영역을 지정합니다. 문구·영역 수정 시 이전 결과는 재검증 대상으로 바뀝니다.
- 이미지 목록에서 통과·확인 필요·미통과·미검증을 구분합니다. 상태 필터와 `다음 확인 대상`으로 아직 확인할 이미지를 이동합니다. 현재 이미지 검증과 선택 검증은 같은 기본 버튼을 사용하며 전체·미검증 재확인은 `일괄 검증`에서 실행합니다.
- 도구 선택·연결 상태·버전·저장 상태는 상단에 표시합니다. 로그인·분석 옵션·자주 쓰는 설정·백업은 `설정`, 저장 폴더 검색·열기·휴지통 복원은 `저장 작업`에서 사용합니다. `임시 저장됨`과 `작업 목록에 저장됨`을 구분합니다.
- 작은 창에서는 패널을 아래로 배치합니다. 버전과 저장 상태는 계속 표시하며 각 작업 패널을 따로 스크롤할 수 있습니다.

## 보고서·검수·자동 가져오기 (0.4.0)

- 왼쪽 `전체 보고서`에서 모든 이미지의 검증 결과를 엑셀·CSV·HTML로 저장합니다. 자동 판정과 수동 검수를 나란히 기록하고 HTML에는 원본 미리보기와 검증 영역 캡처를 포함합니다.
- 결과 항목을 선택한 뒤 `직접 확인 완료` 또는 `문제 있음`과 검수 메모를 저장합니다. 자동 OCR 판정은 유지됩니다. 이미지·문구·무시 영역·인식 결과가 바뀌면 기존 검수는 재검수 대상으로 표시됩니다.
- `엑셀 자동 연결`에서 파일명/화면명·문구·언어·영역 열을 연결합니다. 파일 경로가 정확히 일치하는 이미지를 먼저 선택하고 파일명 또는 기존 화면명으로도 찾습니다. 미리보기에서 연결 안 된 행·중복 이름·입력 오류를 확인합니다. 적용하면 연결된 이미지의 문구를 교체합니다. 언어는 ko/en/ja/zh-CN/zh-TW/de/fr/es/neutral을 사용하고, 영역은 0~1 범위의 x,y,width,height입니다.
- `화면 비교`에서 작업 목록 또는 외부 이미지로 기준을 저장합니다. 기준·현재·변경 영역을 함께 보며 비교 이미지를 내보낼 수 있습니다. 크기 맞추기, 픽셀 단위 위치 보정, 차이 허용치를 제공합니다. 비교는 최대 긴 변 1600px에서 계산하며 OCR 판정과 별도로 표시합니다.
- 문구 설정의 `OCR에서 문구 만들기`는 인식된 글자를 선택해 기대 문구와 영역으로 추가합니다. 새로 읽거나 현재 검증의 인식 결과를 사용합니다. 기대 문구가 올바른지 확인한 뒤 검증하세요.
- `무시 영역 그리기`로 FPS·시계·알림 등을 드래그해 제외합니다. 이미지마다 최대 40개를 저장하며 OCR 입력과 화면 비교에서 함께 제외합니다. 문구의 영역은 별도로 유지됩니다.
- `자동 가져오기`에서 Windows 폴더 선택 또는 경로 입력 후 시작합니다. 앱이 열려 있는 동안 3초마다 새 이미지를 확인하고 파일 크기가 안정된 다음 가져옵니다. 기존 이미지 포함·현재 설정 복사를 선택할 수 있으며, 화면 비율이 다르면 영역 복사를 생략합니다. 하위 폴더는 4단계, 폴더 내 이미지는 2,000개까지 확인합니다. 앱 재실행 후 시작 버튼으로 다시 연결하세요.
- 작업당 최대 200장·합계 512MB를 지원합니다. 한 장은 10MB, 검증 문구는 이미지당 80개입니다. 원본은 개별 파일로 한 번 저장하며 이후에는 파일 참조와 작업 정보만 저장합니다. 기존 작업 파일도 계속 읽습니다.
- `일괄 검증`의 `현재 이미지 후 일시정지`와 `남은 이미지 이어서 검증`을 사용합니다. 각 이미지가 끝날 때 실행 목록과 결과를 PC에 저장하고, 앱 재실행 후 정식 작업 또는 임시 작업을 열어 이어갈 수 있습니다. 이어 실행은 이전 분석 도구·옵션을 복원합니다. 저장 실패 시 일시정지하며, 오류·취소 이미지와 설정이 바뀐 이미지는 다시 처리합니다.
